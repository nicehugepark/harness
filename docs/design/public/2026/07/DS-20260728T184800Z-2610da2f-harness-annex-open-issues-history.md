## 요약

**확정** — 이 문서는 재생성본 전체의 **미결과 이력의 단일 정본**이다. 축 문서는 미결 절에서 자기 축 항목을 서술하고, 전수와 이력은 여기 모인다. 문서마다 이력 절을 두지 않는다 — 이력이 흩어지면 그 자체가 이중 정의다.

**실측 대기** — 이 문서는 실측 항목을 소유하지 않는다. 실측 항목 54건의 색인은 부속 PA다.

**미결** — 미해소 지적 25항(PB§2) · 조립 통일 내역 17건(PB§3) · 자기 일관성 검사 기록(PB§4) · 재생성 라운드가 새로 세운 미결 11항(PB§5). 이 중 완료 조건 미충족으로 보류 중인 것이 2건, 사람 결정 대기가 2건이다. 재작업 라운드가 추가한 2항(PB-N10·PB-N11)은 둘 다 **이번 라운드에서 시정을 마쳤고 산식·스키마 결정만 남은** 것이다.

## 2. 미해소 지적 (25항)


### 2.1 완료 조건 미충족으로 보류 중 (설계 세션이 스스로 완화할 수 없는 것)

- **PB-B1** — **채번 경합 실측 VS1~VS4 미실행** — S§12 T6은 경합 시나리오를 "실제로 돌려서" 검증해야 완료다. 처리 확정(A§12): 별도 실행 과제로 등재(원장 등재는 병행 중·잠정), 실측 착지 전까지 A§3의 무결성 주장은 "설계상 성립" 표기 유지, 구현 단계 이연은 의사결정 문서 상신으로만 유효.
- **PB-B2** — **리드 게이트 조합의 적대 리뷰 통과 대기** — S§5.4·S§12 T3는 채택 조합의 별도 적대 리뷰 통과를 완료 조건으로 요구한다. F§7.6이 그 대기 상태를 명시한다. 관련: 3장·6장은 문서 status상 적대 리뷰 반영 라운드를 거치지 않은 초안이다(1·2·4·5장은 1라운드 must-fix 반영판).

- **PB-B8** — **조립 문서의 type과 슬롯 린트 적용 대상** — **해소**: 조립 문서의 frontmatter `type`을 A§4.4의 통일 규칙(설계 문서 type은 `design` 단일값)대로 정규화해 F§9.1의 적용 enum {design, decision, norm, charter}에 포함시켰다. 이형 type을 enum에 추가하는 경로는 채택하지 않는다 — 이형 허용은 A§4.4가 금지한 우회 표면을 다시 여는 것이기 때문. 손 적용 판정 기록은 PB.
- **PB-B9** — **섹션 산출물 디렉토리의 중립명 개명** — A§12의 공유 새니타이즈 항목. 조립 산출물(본 문서)은 중립명 경로에 착지했으나 원 섹션 디렉토리 개명은 후속 처리로 남는다.

## 5. 재생성 라운드의 신규 미결 (11항)

재구조화 라운드에서 새로 확인됐고 이번 범위에서 처리하지 않은 것들이다. **내용 변경을 형태 변경에 섞지 않는다**는 규율에 따라 시정을 별도 경로로 남긴다 — 재생성본과 원자료의 차이가 곧 형태 변경분이어야 무손실 대조가 성립하기 때문이다.

| 항목 | 미결 | 처리 상태 |
|---|---|---|
| PB-N1 | 문서 유형 어휘 모순 — 규율 슬롯 린트의 적용 대상 선언이 착지 게이트가 강제하는 유형 코드 집합과 겹치지 않아, 규격대로 착지한 문서가 린트 적용 대상이 되지 않는다. | 설계가 트리거를 내용 기반(본문에 규율 항목 표기가 1건 이상 존재하는 문서)으로 재선언하기로 결정했으나, **재생성본에는 반영하지 않았다** — 재생성 범위는 형태이고 스키마 변경은 내용이다. 시정은 별도 요청. |
| PB-N2 | 참조 슬롯 `refs.spec` 과 진입점의 `refs.parts` 신설이 스키마 판 상승을 요구하는 변경인지 미확정. | 참조 필드가 슬롯 맵으로 열려 있어 선택 슬롯 추가는 판 상승 없이 가능해 보이나 판정 근거가 없다. 리허설에서는 선택 슬롯으로 썼다. |
| PB-N3 | 주소 접두 필드 `addr` 신설의 스키마 지위 미확정. | 구조 검사기가 파일에서 문서 접두를 얻는 유일한 경로다. 이 필드가 없으면 검사기가 손 목록을 요구하게 되고 손 나열 금지 규율이 깨진다. 판 상승이 필요하다는 판정이 나오면 11본 전건의 frontmatter 를 손대야 한다. |
| PB-N4 | 문서 산출에 걸리는 증거 계약(`tdd_evidence` 5필드)의 적정 형태 미확정. | 재생성본은 코드가 아니라 문서라 파일 단위 실패 테스트가 성립하지 않는다. 이번 라운드는 원자료에 대한 구조 검사 실행 기록을 선행 실패 증거로 삼고 이탈 고지 필드에 그 사실을 적었다 — 계약이 마련한 고지 슬롯을 쓴 것이지 계약을 비운 것이 아니다. 적정 형태는 문서 체계 축의 결정 대상. |
| PB-N5 | 정제 스캔이 대소문자 구분 실행에 의존한다. | 검증 기준 라벨을 대문자로 쓰고 정제 목록에는 같은 글자의 소문자 판 번호 패턴이 있다. 대소문자 구분 실행에서는 검출 0건이지만 무시 옵션이 붙으면 산출 전건이 오탐된다. 근원 처방은 스캔 명령을 고정 스크립트로 두는 것이다. |
| PB-N6 | 규율 항목 39건 중 장치 슬롯의 브랜치가 한쪽뿐인 17건의 보강 여부. | 원자료 실측은 양 브랜치 비공백 22건 · 장치 브랜치만 16건 · 장치 불가 브랜치만 1건이다. 이 분포를 바꾸는 것은 형태 변경이 아니라 내용 생성이므로 그대로 이관했다. 목록은 PC§4 의 브랜치 열이 정본. |
| PB-N7 | 무손실 매핑의 자산 식별자 산식이 삽입에 취약하다. | 설계는 헤딩·다이어그램·펜스·표의 식별자를 등장 순서로 정했는데, 재생성에서 절이 하나만 삽입돼도 이후 순서가 전부 밀려 좌우변 대조가 무력해진다. 이번 라운드는 **좌변 식별자를 원자료 등장 순서로 고정하고 우변은 주소로 대조**해 회피했다. 산식 자체의 개정은 다음 라운드 대상. |
| PB-N8 | 부속의 기계 판독 블록을 코드펜스가 아니라 표로 적었다 — 검사기와 기준 문면의 갈림. | 검증 기준 1의 문면은 부속에 "판정식·문법·스키마 코드펜스 0건"을 요구하는데 검사기 구현은 **모든 비 mermaid 코드펜스**를 계수한다. 매핑 데이터는 판정식·문법·스키마가 아니지만 검사기는 구분하지 못한다. 이번 라운드는 기준 문면과 검사기를 동시에 만족시키는 표 표기를 택했다. 어느 쪽을 정본으로 삼을지는 다음 라운드 결정 대상. |
| PB-N9 | 구조 검사기의 무자격 참조 판정식이 한 글자 문서 접두를 오검출한다. | 설계에 실린 검사기는 절 기호 앞 3자를 잘라 뒤 2자로 접두를 판정하는데, 여는 괄호나 세로줄 바로 뒤에 한 글자 접두가 오면(예: 괄호 다음의 축 접두) 접두가 없는 것으로 계수된다. 두 글자 접두는 영향이 없다. 이번 라운드는 판정식을 **절 기호 직전 토큰의 경계 일치**로 고쳐 실행했다. 설계 문서 쪽 판정식의 갱신이 남는다. |
| PB-N10 | 절 주소 변환기의 **연쇄 자격 상속** 규칙이 자격을 잘못 상속시킬 수 있다. | 변환기는 가운뎃점·쉼표로 이어진 절 참조 연쇄에서 직전 참조의 문서 자격을 상속시킨다. 원자료가 스펙 참조 하나를 적고 쉼표로 이어 접두 없는 참조를 하나 더 적은 자리에서, 둘째 참조가 스펙 자격을 물려받았다. 그러나 스펙의 해당 절은 소절을 갖지 않고, 같은 개념(기록 평면은 엔진·브랜치와 무관하게 항상 하나)을 담은 절은 B§7.2다 — 같은 원자료가 다른 자리에서 이 개념을 자기 장 지시로 부른 것이 판독 근거다. **재작업 라운드에서 개별 판독 확정분으로 정정**했고 미해소 참조는 0건이 됐다. 남은 것은 산식이다 — 연쇄 상속을 유지할지, 유지한다면 상속 결과를 주소 실재 검사와 결합해 강제할지가 다음 라운드 결정 대상. 형태 검사(접두 유무)만으로는 이 계열이 잡히지 않는다. |
| PB-N11 | 원자료에서 **승계된 결번·결함**을 매핑 스키마의 어디에 표시할지 미확정. | 착지 게이트 오류 코드 집합이 한 번호를 건너뛰는데(A§5.2) 원자료에도 같은 결번이고 사유 기록이 없다. 무손실 관점에서는 정상 이관이지만, "승계"라는 사실을 담을 자리가 매핑 연산 어휘(유지·이동·분할·병합·승격·삭제) 안에 없다. 재작업 라운드는 **연산 어휘를 건드리지 않고** 별도 절(PC§5.6 승계 항목)을 열어 표시 자리를 만들었다 — 어휘는 자산의 이동을 서술하는 축이고 승계는 자산의 품질을 서술하는 축이라 같은 축에 섞으면 둘 다 흐려지기 때문이다. 승계 축을 정식 스키마 열로 승격할지는 다음 라운드 결정 대상. |
